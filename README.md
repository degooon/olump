# Мебельный склад «Олимп» — лендинг

Статический лендинг на Vite. Вёрстка HTML + CSS + ванильный JS, без фреймворков.

## Команды

```bash
npm install        # установить зависимости (один раз)
npm start          # dev-сервер с автоперезагрузкой на http://localhost:3000
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр собранного dist/
```

## Структура

```
src/
├─ index.html        # разметка
├─ styles/style.css  # стили
├─ js/main.js        # логика каталога, фильтров, корзины
├─ img/
│  ├─ bg/            # фоновые картинки
│  └─ cards/         # картинки товаров для карточек
└─ public/           # файлы, копируемые в dist как есть (favicon, robots.txt)
dist/                # результат сборки (не коммитится)
```

## Как добавлять картинки

- Клади фон в `src/img/bg/`, картинки карточек в `src/img/cards/`.
- Ссылайся на них относительным путём, например в CSS: `background-image: url(../img/bg/hero.jpg)`,
  в HTML: `<img src="./img/cards/sofa-gera.jpg" alt="Диван Гера">`.
- При `npm run build` картинки автоматически оптимизируются (sharp + svgo).

## Что даёт сборка

- Разбивка на отдельные файлы (index.html / style.css / main.js).
- Autoprefixer — кросс-браузерные CSS-префиксы.
- Минификация HTML/CSS/JS в проде.
- Оптимизация изображений.
- Dev-сервер с горячей перезагрузкой.

## Перед выкладкой

В `src/js/main.js` замени плейсхолдер `ORDER_PHONE = '78000000000'` на реальный номер
WhatsApp клиента (формат `7XXXXXXXXXX`, без `+` и пробелов).
